# Avispon Viz

**Vision-Guided Autonomous Drones for Real-World Indoor Missions**

🌐 **Live Website:** [https://avispon-viz.vercel.app/](https://avispondrones.vercel.app/)

Welcome to the official repository for the **Avispon Viz** website. We are dedicated to building the future of indoor autonomy by integrating edge AI and advanced onboard vision into nano-UAV platforms.

## About the Project
Avispon Viz focuses on deploying cutting-edge autonomous solutions in constrained, GPS-denied environments where traditional drones fail. We specialize in custom hardware modifications, intelligent firmware, and lightweight edge compute modules that enable true autonomy.

### Key Capabilities
- **Onboard Vision & AI**: Advanced perception algorithms running directly on the drone.
- **Custom Firmware**: Tailored control systems for precise indoor flight.
- **Nano-UAV Platforms**: Extremely small form-factor drones capable of navigating tight spaces.
- **Real-World Applications**: Optimized for inspections, mapping, and surveillance in industrial and confined areas.

## Deployment
This website is built with vanilla HTML, CSS, and JS, meaning it can be hosted statically on any standard web server or directly via **GitHub Pages**. 

To deploy on GitHub Pages:
1. Navigate to **Settings > Pages** in your repository.
2. Select **Deploy from a branch**.
3. Set the branch to `main` and save.
4. Your site will be live in minutes!
