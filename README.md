## 🚀 Hosting on Vercel (Step-by-Step Guide)

This website is optimized for instantaneous deployment on **Vercel** with full static site caching, security headers, and automated sitemap routing defined in `vercel.json`.

### Option 1: Automatic Deployment via GitHub Integration (Recommended)
1. Push this repository to your GitHub account (`AVISPON-VIZ/Avispon_Viz`).
2. Log in to [Vercel](https://vercel.com/) with your GitHub account.
3. Click **"Add New..."** → **"Project"**.
4. Import the `Avispon_Viz` repository.
5. Keep Framework Preset as **Other / Static HTML**.
6. Click **Deploy**. Vercel will build and assign your site a live URL (e.g., `https://avispon-viz.vercel.app`).
7. Any future code push to the `main` branch will automatically re-deploy your website!

### Option 2: Deploy using Vercel CLI (Command Line)
1. Open terminal in the project directory:
   ```bash
   npx vercel
   ```
2. Follow the prompts to log in and select your scope.
3. To deploy directly to Production, run:
   ```bash
   npx vercel --prod
   ```

### Option 3: Drag & Drop via Vercel Dashboard
1. Go to [Vercel New Project Upload](https://vercel.com/new).
2. Drag and drop the `Avispon_Viz` workspace folder directly into the browser.
3. Click **Deploy**.

## 📌 3 Quick Steps to Get Indexed by Google Immediately

After hosting on Vercel:

1. **Submit to Google Search Console:**
   - Go to [Google Search Console](https://search.google.com/search-console).
   - Add your live site URL (e.g., `https://avispon-viz.vercel.app` or your custom domain).
   - Verify ownership (automatic if using domain DNS or Vercel meta tag).
   - Click on **Sitemaps** on the left menu and enter: `sitemap.xml` → Click **Submit**.

2. **Request Indexing:**
   - Paste `https://avispon-viz.vercel.app/` into the URL Inspection bar at the top of Google Search Console.
   - Click **Request Indexing**. Googlebot will crawl and index your site within 24-48 hours.

3. **Submit to Bing Webmaster Tools:**
   - Visit [Bing Webmaster Tools](https://www.bing.com/webmasters).
   - Import your site directly from Google Search Console with one click.
